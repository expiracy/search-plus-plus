Search everything in VS Code from one popup.

Miss Search Everywhere from IntelliJ, WebStorm, or PyCharm? search++ brings it to VS Code. Press Shift Shift and type to find files, folders, text, symbols, usages, and commands.

Version {{version}}. Works on macOS, Windows, and Linux with VS Code 1.96 or later. Source on GitHub

Search modes

Click a mode or press Tab to switch. Your query stays in the search box.

Files, folders, text, symbols, and commands, shown in grouped sections.

File names and paths across your workspace. Add :42 or :42:5 to open a file at a line and column.

Folders in your workspace. Pick one to reveal it in the Explorer.

Text across every file, with the matching line shown under each result. Supports regex, case, and whole-word matching.

Classes, functions, and variables from your installed language extensions. Show usages with Cmd+Return on Mac or Ctrl+Enter on Windows/Linux. Shift+F12 also works inside the popup.

Select a symbol to list its references. Type over the name to filter by text or file.

All VS Code commands, built in and from extensions.

Key features

Press → on a result to show it in the editor while the popup stays open. The editor scrolls to the matching line. Previews reuse one editor tab. Return on Mac or Enter on Windows/Linux opens the result normally.

References come from VS Code's language providers, so they are semantic references rather than text matches. Type over the symbol name to filter the list by text or file name.

Add :line or :line:column after a file name to open the file at that position. Absolute paths to files outside the workspace also work.

Press Alt+F (⌥+F on Mac) or click the sparkle button to turn on fuzzy matching for files, folders, symbols, usages, and commands. A result matches when the letters you type appear in its name or path in order, so a few characters are enough to find a long path. Case-sensitive and whole-word toggles sit next to it, plus regex for text search.

Files matched by .gitignore are excluded by default, and a .searchignore file can exclude more. File search uses an in-memory index with fzf matching. Text search uses ripgrep.
