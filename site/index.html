Six search modes

Click a mode or press Tab to switch. Your query stays in the search box.

Everything

The best matching files, folders, text, symbols, and commands, grouped in one list.

Files

File names and paths across your workspace, from an in-memory index with fzf matching.

Folders

Folders with searchable files. Open one to reveal it in the Explorer.

Text

File contents, including notebook cells, streamed from ripgrep with the matching line under each result.

Symbols

Classes, functions, and variables from your language extensions.

Usages

Every reference to the selected symbol. Press Cmd+ReturnCtrl+Enter on a symbol to get here.

Commands

Every VS Code command, built in and from your extensions.

More features

Preview
Press → at the end of your query, or click a row's eye button, to show a result in the editor while the popup keeps focus.
Find usages
Press Cmd+ReturnCtrl+Enter on a symbol to list its references. Type to filter them; Back returns to your search.
Go to line
Type file.ts:14 or file.ts:14:5 to open a file at a line and column. Full paths work outside the workspace.
Recent history
An empty search lists your last 20 files and locations. Turn on rememberLastSearch to reopen with your last query instead.
Search options
Case sensitive, regex, whole word, and fuzzy matching, each on a toggle and a shortcut.
Ignore files
.gitignore, .searchignore, and excluded globs keep generated and vendored files out.
Your layout
Reorder or hide tabs, pick the starting tab, and add VS Code or IntelliJ style shortcuts.
Fast on big repos
Files come from an in-memory index; text streams from ripgrep as you type.
Remote workspaces
Text search runs on the remote extension host when ripgrep is available there.
